# Marketing

Launch material for WSLC AI Agent. **This folder never goes to the public
repository**, like `OWNER-NOTES.md`: leave it out of every copy to
`Berpiztu/wslc-ai-agent`.

| File | What |
|---|---|
| [launch-plan.md](launch-plan.md) | When and where to publish, and what to do the first hours |
| [x-posts.md](x-posts.md) | The posts for X: the quote of the WSLC announcement, alternatives, the thread, answers to likely questions |
| [x-article.md](x-article.md) | The long X article, ready to paste |
| [media/](media/) | Videos and images to attach |

## Media

| File | For |
|---|---|
| `media/wslc-ai-agent-mcp.mp4` | The main post: the MCP diagram animated (7 s, 1280×704) |
| `media/wslc-ai-agent-overview.mp4` | The whole architecture animated, for the thread or the article |
| `media/article-cover.png` | The article's cover (1500×600, the 5:2 X asks for). Provisional: a crop of the diagram |
| `media/article-mcp.png`, `media/article-overview.png` | Stills of the two diagrams, every node lit, for the article |
| `media/architecture-*.png`, `media/architecture-*.webp` | The README's diagrams |

The videos and stills are made from the Archify diagrams with the trace
motion on (how: `OWNER-NOTES.md`, "The README's animated diagrams").
